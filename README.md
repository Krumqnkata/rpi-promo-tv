# PromoTV – рекламни видеа на телевизор с Raspberry Pi

Raspberry Pi 3 Model B+ пуска видеа и снимки на телевизора в цикъл. Управлява се по два начина:

- **от телефон.** Пи-то създава своя Wi-Fi мрежа и след свързване се отваря уеб панел. В него се качват и трият файлове, подреждат се, настройва се графикът и се включва или изключва телевизорът;
- **от дистанционното на телевизора** през HDMI-CEC, чрез меню на екрана.

## Какво може

| | |
|---|---|
| Файлове | Качване (с прогрес), изтриване, преименуване, подреждане, включване/изключване от списъка, „Пусни сега“, миниатюри |
| Предупреждения | При качване всеки файл се проверява. Ако Pi 3 няма да го пусне гладко (не е H.264, над 1080p, над 30 кадъра/сек, 10-бита), се показва предупреждение |
| Промоции с период | Всеки файл може да има начална и крайна дата („от 1.12 до 24.12“). Извън периода не се показва, но не се изтрива |
| Показване | Целия списък по ред, разбъркано или един файл в цикъл. Колко секунди стои всяка снимка. Сила на звука. Плавен преход (затъмняване) между снимките |
| Преглед на екрана | „Покажи екрана“ в панела показва текущия кадър от телевизора |
| График | Различни часове за включване и изключване за всеки ден, включително през полунощ (напр. 18:00–02:00) |
| Телевизор | Ръчно включване и изключване от панела и от менюто на телевизора. Ако телевизорът не се изключи по CEC, Пи-то спира HDMI сигнала и телевизорът заспива сам |
| Час | Pi 3 няма часовник с батерия. Часът се сверява автоматично от телефона при всяко отваряне на панела или ръчно от менюто на телевизора |
| Wi-Fi | Мрежа с парола (WPA2). Името и паролата се сменят от панела |
| Защита на SD картата | Системата е „само за четене“, така че спирането на тока не може да я повреди. Видеата и настройките се записват нормално |
| Watchdog | Ако програмата блокира, се рестартира сама след 90 сек. Ако цялото Пи замръзне, се рестартира след 15 сек |
| Резервно копие | Подредбата, периодите, графикът и настройките се изтеглят като файл и се възстановяват, например на второ Пи |

## Какво ви трябва

- Raspberry Pi 3 Model B+, захранване 5V 2.5A, microSD карта (32 GB);
- HDMI кабел до телевизор Hisense;
- компютър, от който да запишете картата, и **интернет за инсталацията** (Ethernet кабел или домашен Wi-Fi). След това интернет не е нужен.

## Инсталация

### 1. Запишете системата

1. Инсталирайте [Raspberry Pi Imager](https://www.raspberrypi.com/software/).
2. Изберете **Raspberry Pi 3**, после **Raspberry Pi OS (other) → Raspberry Pi OS Lite (64-bit)**.
3. В настройките (иконата със зъбно колело / „Edit settings“) задайте:
   - потребител и парола;
   - домашния Wi-Fi (само за инсталацията);
   - **Services → Enable SSH**.
4. Запишете картата, сложете я в Пи-то, свържете HDMI и захранването.

### 2. Качете програмата

Тук има два варианта.

**С git**, ако хранилището е публично или Пи-то има достъп до GitHub. От компютъра:

```powershell
ssh потребител@raspberrypi.local
```

После на Пи-то:

```bash
sudo apt-get install -y git
git clone https://github.com/Krumqnkata/rpi-promo-tv.git
cd rpi-promo-tv
```

**Без git.** От PowerShell на компютъра, в папката на проекта:

```powershell
scp -r promotv deploy install.sh потребител@raspberrypi.local:~/rpi-promo-tv/
```

### 3. Инсталирайте

На Пи-то:

```bash
cd ~/rpi-promo-tv
sudo ./install.sh
```

По подразбиране мрежата се казва **PromoTV** и паролата се генерира случайно. Можете да ги зададете сами:

```bash
sudo WIFI_SSID="Магазин TV" WIFI_PASSWORD="moqtaparola" ./install.sh
```

Накрая скриптът показва името на мрежата, паролата и адреса. **Запишете ги** и рестартирайте:

```bash
sudo reboot
```

> След рестарта Пи-то вече не се свързва с домашния Wi-Fi, защото единственият му Wi-Fi чип става точка за достъп. SSH работи през мрежата PromoTV (`ssh потребител@192.168.4.1`) или през Ethernet кабел.

Инсталацията включва и **защитата на SD картата** (системата става само за четене след рестарта). Ако не я искате, инсталирайте с `sudo PROTECT=0 ./install.sh`. По-късно може да се включва и изключва от панела („Настройки“) или с командата `sudo promotv-protect on|off|status`.

### 4. Настройте телевизора Hisense

Включете HDMI-CEC: **Настройки → Система / Устройство → HDMI и CEC → CEC функция: Вкл.** (името на менюто зависи от модела, понякога е „HDMI CEC“ или „Anynet+“). Включете също „Автоматично включване на ТВ“ (TV Auto Power On) и „Автоматично изключване на устройството“, ако ги има.

## Използване

### От телефон

1. Свържете се към Wi-Fi **PromoTV** с паролата.
2. Страницата обикновено се отваря сама („Влезте в мрежата“). Ако не се отвори, въведете **http://192.168.4.1** в браузъра.
3. За качване на големи видеа използвайте нормалния браузър (Chrome или Safari), а не малкия прозорец, който се отваря автоматично.

Телефонът ще покаже „Няма интернет“. Това е нормално: мрежата е само за управление.

### От дистанционното на телевизора

| Бутон | Действие |
|---|---|
| **OK**, ▲ или ▼ | отваря менюто |
| ► / ◄ (при затворено меню) | следващ / предишен файл |
| Play / Pause | пауза / продължи |
| Back | назад / затваря менюто |

В менюто има: пауза, следващ и предишен файл, избор на файл, смяна на режима, изключване на телевизора, **сверяване на часа**, **Wi-Fi данни с QR код** и информация (свободно място, график, IP).

Ако дистанционното не управлява менюто, телевизорът не предава бутоните по CEC за този вход. Тогава проверете CEC настройките и се уверете, че е избран HDMI входът на Пи-то.

## Важно за часа

Raspberry Pi 3 няма вграден часовник. При спиране на тока часът се връща към последния запазен (до 1 час назад плюс времето без ток). Сверява се по три начина:

- автоматично, всеки път когато отворите панела от телефон;
- ръчно, от менюто на телевизора → „Сверяване на часа“;
- автоматично от интернет, ако включите Ethernet кабел с интернет.

Докато часът не е сверен след включване, панелът показва предупреждение, а часовникът горе свети в жълто. За напълно автономна работа може да се добави RTC модул DS3231 (около 5 лв.).

## Препоръки за видеата

- **MP4 с H.264**, до **1920×1080**, до **30 кадъра/сек**, 8-битово;
- H.265/HEVC, 4K и 60 кадъра/сек насичат на Pi 3. Панелът предупреждава за такива файлове;
- конвертиране на компютър с [HandBrake](https://handbrake.fr/): Preset **Fast 1080p30**;
- снимки: JPG или PNG, най-добре 1920×1080.

## Отстраняване на проблеми

| Проблем | Решение |
|---|---|
| Черен екран | `sudo journalctl -u promotv -n 100`. В `/etc/promotv/mpv.conf` пробвайте `vo=drm` вместо `vo=gpu`, после `sudo systemctl restart promotv` |
| Няма звук | `mpv --audio-device=help` и сменете `audio-device` в `/etc/promotv/mpv.conf` |
| Телевизорът не се включва или изключва | Проверете CEC в настройките на телевизора. Тест: `echo 'on 0' \| cec-client -s -d 1` (първо спрете услугата: `sudo systemctl stop promotv`) |
| Не виждам Wi-Fi мрежата | `nmcli connection up promotv-ap` и `journalctl -u NetworkManager -n 50` |
| Забравена Wi-Fi парола | Менюто на телевизора → „Wi-Fi и уеб панел“ |
| Телевизорът показва „няма сигнал“ | Пи-то е спряло HDMI сигнала, защото телевизорът не е потвърдил изключването по CEC. Натиснете „ТВ вкл.“ в панела. Ако се случва често, изберете „Само HDMI-CEC“ в „Настройки → Изключване на телевизора“ |
| Червено предупреждение „папката не е достъпна за запис“ | Защитата е включена, но папката с данни не е монтирана. `sudo systemctl status promotv-data`. Изключете защитата от панела, докато се оправи |
| Промените в системата изчезват след рестарт | Защитата на картата е включена (това е целта ѝ). `sudo promotv-protect off`, направете промените, после `sudo promotv-protect on` |

Полезни команди:

```bash
sudo systemctl status promotv      # състояние
sudo journalctl -u promotv -f      # логове на живо
sudo systemctl restart promotv     # рестарт на програмата
```

Файловете се пазят в `/var/lib/promotv/media`, а настройките в `/var/lib/promotv/state.json`.

## Обновяване

При включена защита на картата първо я изключете (Пи-то ще се рестартира):

```bash
sudo promotv-protect off
```

После свържете Пи-то с интернет (Ethernet кабел) и обновете. Инсталацията включва защитата отново:

```bash
cd ~/rpi-promo-tv && git pull && sudo ./install.sh && sudo reboot
```

Името и паролата на мрежата, файловете и настройките се запазват.

## Разработка на компютър

Уеб панелът може да се пусне и на Windows/Linux без Raspberry Pi. Плеърът и CEC се симулират:

```powershell
pip install flask qrcode
$env:PROMOTV_DEV = "1"; python -m promotv
```

После отворете http://localhost:8080. Данните се пазят в `./devdata`.

## Как е устроено

```
promotv/
  app.py        свързва всичко
  player.py     mpv през JSON IPC (плейлист, пауза, OSD слоеве)
  cec.py        cec-client: вкл./изкл. на телевизора, бутони от дистанционното
  tvmenu.py     менюто на екрана (рисува се с OSD на mpv)
  scheduler.py  седмичен график
  media.py      файлове, ffprobe проверка, миниатюри, предупреждения
  system.py     час, Wi-Fi (NetworkManager), рестарт
  web.py        Flask API + captive portal
  static/       уеб панелът
deploy/         systemd услуги, mpv.conf, watchdog, защита на картата (promotv-data, promotv-protect)
install.sh      инсталация
```
